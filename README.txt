HTAC CONNECT - Student & Parent Information Portal

Database-free static website.

HOW TO USE:
1. Extract the ZIP.
2. Open index.html in a browser to test locally.
3. Replace placeholder school information in the HTML files.
4. Edit data in js/announcements.js, js/calendar.js and js/resources.js.
5. Upload the complete folder to any static web host.

No database, backend, or server-side code is required.
